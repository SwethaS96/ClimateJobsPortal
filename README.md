# ClimateJobsPortal

A starter project for collecting, parsing, and serving climate job listings.

This repository contains scaffolded folders for scraping, parsing, backend, AI search, and configuration.

## Folder Responsibilities

- `models` — Python data models representing your entities.
- `database` — SQLite connection, schema creation, CRUD operations.
- `scraper` — Download HTML/PDFs from websites.
- `parser` — Extract structured data from website HTML.
- `backend` — FastAPI application and API endpoints.
- `frontend` — HTML templates, CSS, JavaScript.
- `config` — Centralized configuration.
- `utils` — Reusable helper functions (hashing, logging, dates).
- `logs` — Runtime logs.
- `data` — SQLite database, downloaded PDFs, cache files.
- `tests` — Unit and integration tests.
